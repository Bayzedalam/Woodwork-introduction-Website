EVERLAST — EDGE PROFILE COLLECTION 2026
=========================================

Files
- index.html : catalogue website structure and content
- style.css  : responsive layout, typography, colours, imagery and modal styling
- script.js  : profile detail modal, category filters and mobile navigation

How to preview
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Internet access is required for Google Fonts and the remote Unsplash lifestyle images.

Before publishing
- Replace hello@everlast.com.sg with the client's confirmed email address.
- Add the confirmed WhatsApp number, website and WhatsApp QR code if available.
- Confirm each profile's technical geometry and applicable PVC tape thickness (0.5–0.6 mm or 1.0 mm) with the client.
- Current profile imagery is illustrative lifestyle imagery; it does not certify or precisely depict the actual profile geometry.
- Replace the remote image URLs with approved/licensed client images before final commercial publication.
- This is a front-end concept. The contact CTA uses an email link and does not submit to a server.

The site is responsive and includes profile category filters, detail popups, mobile navigation and anchor navigation.
